Clés des notifications

Cette page crée la paire de clés qui signe la notification du matin. Tout se passe dans ton navigateur : rien n'est envoyé nulle part.

À faire une seule fois. Si tu recommences, il faudra réactiver les notifications sur chaque téléphone.

GitHub → dépôt allezhop → Settings → Secrets and variables → Actions → New repository secret. Nom : VAPID_PRIVATE_KEY, valeur : la clé privée.
